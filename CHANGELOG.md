# Registro de cambios

Todos los cambios relevantes de TextilCalc se documentan en este archivo.

## [1.1.2] - 2026-11-13

### Añadido

- Comportamiento reutilizable para ejecutar cálculos mediante la tecla Enter.
- Script reproducible para generar la APK Android de entrega.

### Cambiado

- Rediseño adaptable de las pantallas principales y estilos compartidos.
- Mejoras en los flujos de cálculo, gramatura, metraje y gestión de telas.
- Configuración Android Release para conservar las dependencias requeridas por LiteDB y AndroidX.

### Verificado

- Compilación Release para `net10.0-android`.
- 13 pruebas unitarias superadas.
- Instalación y arranque de la APK en un emulador Android.
